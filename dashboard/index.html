02 / Behind the numbers

Open sources. Explicit assumptions.
01

Real traffic, clear coverage

BTS T-100 Domestic Segment, all carriers. Full-year 2025 and the latest published months of 2026. Only scheduled passenger service, passenger-configured aircraft, and routes with operated seats are included.

Official source ↗
02

A transparent QSI proxy

Score = scheduled departures per day × √(average aircraft seats / 150). Normalize scores across the route’s reporting airlines to obtain QSI share. Weights are assumptions, not fitted passenger preferences.

Nonstop only. No time-of-day, connection, fare, brand or loyalty effects. Missing schedule totals produce an unavailable QSI share.

03

Built to be reproducible

Python transforms the source into compressed Parquet and a PostgreSQL star schema. Supabase serves read-only reporting views. Vercel hosts this dashboard, with refresh orchestration in GitHub Actions.
