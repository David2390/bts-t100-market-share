3. Run the aggregation pipeline; verify shares sum to one where denominators are positive.

## Acceptance criteria
- All reported figures trace to the downloaded source.
- Share denominators include all included reporting competitors.
- Missing denominators remain blank, not fabricated zeroes.
- Findings distinguish observed traffic from schedule-based opportunity and itinerary demand.
- Reproduction instructions work from a fresh checkout plus the documented source file.
